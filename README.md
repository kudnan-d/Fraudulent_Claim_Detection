# Fraudulent Insurance Claim Detection

This project focuses on identifying fraudulent insurance claims using supervised machine learning techniques. The dataset contains real-world-like insurance claim records, and the objective is to build a predictive model that can classify whether a claim is likely to be fraudulent.

## 📁 Repository Structure
├── data/insurance_claims.csv               # Dataset used for training and evaluation
├── Fraudulent_Claim_Detection_Starter.ipynb  # Jupyter Notebook with initial data exploration and model development
└── README.md                          # Project overview and instructions
